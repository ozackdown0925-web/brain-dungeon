# GAS（データの窓口）の設定手順

スプレッドシートの Apps Script を、このフォルダの `Code.gs` に入れかえる手順です。
clasp（PC から Apps Script にファイルを送る道具）を使います。PC のコマンドプロンプト（または PowerShell）で行います。

- 鍵・GAS の URL・スクリプトID は、このリポジトリにもチャットにも書かない。
- GAS は画面を配りません（旧画面「毎日4問ドリル」は 2026-10-27 に消しました。鍵なしで問題・答え・記録が見えてしまうため）。URL だけを開くと `{"error":"forbidden"}` が出ます。

## 1. clasp の準備（1回だけ）

1. Node.js が入っていなければ入れる（https://nodejs.org の「LTS」）。
2. `npm install -g @google/clasp`
3. https://script.google.com/home/usersettings を開き、「Google Apps Script API」をオンにする。
4. `clasp login` → ブラウザが開くので、スプレッドシートの持ち主の Google アカウントで許可する。
   - ログインの情報は `C:\Users\<名前>\.clasprc.json` に入る（リポジトリの外。コミットしない）。

## 2. 今の版の控えをとる（入れかえる前に毎回でなくてよい。最初の1回は必ず）

1. スプレッドシート →「拡張機能」→「Apps Script」→ 左の歯車「プロジェクトの設定」→「スクリプト ID」をコピー。
2. リポジトリの**外**に空のフォルダを作って、そこで clone する。
   ```
   mkdir C:\Users\ozack\code\gas-backup
   cd C:\Users\ozack\code\gas-backup
   clasp clone <スクリプトID>
   ```
   今動いている `Code.gs`・`appsscript.json`・`.clasp.json` などが入る。これが控え。
3. 控えに `Code.gs`・`appsscript.json` 以外のファイルがあれば Claude に知らせる（clasp push は、手元にないファイルを Apps Script から消すため。旧画面の `index.html`・`editor.html`・`drillcore.html`・`theme.html` は消してよい）。

## 3. このフォルダから送る

1. 控えの `.clasp.json` と `appsscript.json` を、このフォルダ（`gas\`）にコピーする。
   - `.clasp.json` はコミットしない（`.gitignore` に入れてある）。中の `"rootDir"` があれば消すか `"."` にする。
2. 送る：
   ```
   cd C:\Users\ozack\code\brain-dungeon\gas
   clasp push
   ```
   「Manifest file has been updated. Do you want to push and overwrite?」と聞かれたら `y`。
3. Apps Script の画面を開き直し、関数の選択で `setup` を選んで「実行」。下の「実行ログ」に次が出る。
   - 管理用の鍵（今までと同じ）
   - **プレイヤー用の鍵（child）**：子どもの iPad に入れる鍵
   - **プレイヤー用の鍵（parent）**：保護者が遊ぶときに入れる鍵
   - 2つのプレイヤー用の鍵は、成績管理フォルダの `drill\記録の読み出し先.txt` に書き足しておく。
   - シート「セーブ」「セーブの控え」「冒険の記録」ができる。「記録」シートの右に「プレイヤー」列ができる（今までの行は子どもの記録として扱う）。
   - 初めて実行するときは、許可の画面が出る（「詳細」→「（安全ではないページ）に移動」→「許可」）。
4. **保護者の暗証番号を入れる**（1回だけ）：スプレッドシートを開き直すと、上のメニューに「Brain Dungeon」が出る。
   「Brain Dungeon」→「保護者の暗証番号を入れる」→ 決めた4けたの番号を入れて OK。
   - 番号は固定。ゲームの画面からは変えられない。変えたいときも、同じメニューから入れ直す。
   - 番号はこのリポジトリにもプログラムにも書かない（公開されるため）。GAS の設定の中に、元にもどせない形で入る。
5. 公開（URL はそのまま）：
   ```
   clasp deployments
   ```
   で出る一覧のうち、`@HEAD` ではない方（今の URL のもの）の ID を使って、
   ```
   clasp deploy -i <デプロイID> -d "G-1"
   ```
   - clasp を使わずに、Apps Script の画面の「デプロイ」→「デプロイを管理」→ 鉛筆 →「バージョン：新バージョン」→「デプロイ」でもよい。

## 4. 確かめる

ブラウザで次を開く（`<URL>` は今のウェブアプリの URL、`<鍵>` は child の鍵）。
```
<URL>?action=check&key=<鍵>
```
`{"role":"player","player":"child","ok":true}` と出ればよい。
今の iPad のドリルも、いつもどおり開けて解けることを確かめる。

## 5. ゲームをつなぐ（iPad・保護者の端末で1回だけ）

1. ゲーム（`https://ozackdown0925-web.github.io/brain-dungeon/game.html`）を開く。
2. 「はじめに（保護者むけ）」の画面で、**GAS の URL**（記録の読み出し先.txt の「ウェブアプリのURL」）と**プレイヤー用の鍵**を入れて「つなぐ」。
   - 子どもの iPad には child の鍵、保護者の端末には parent の鍵。
   - URL と鍵は、その端末のブラウザが覚える（リポジトリにもコードにも書かない）。長い URL は、PC からメモアプリや AirDrop で iPad に送ってコピーすると楽。
   - はじめてつないだとき、その端末にあったゲームのデータ（テストで遊んだもの）は捨てて、GAS のセーブを使う（なければキャラクリから）。
3. ホーム画面に追加するときは、Safari の「共有」→「ホーム画面に追加」。ホーム画面から開いたときに、もう一度つなぎ先を聞かれることがある（Safari とホーム画面で覚える場所が別のため）。そのときはもう一度入れる。
4. つなぎ先を変えたいとき：保護者画面の「つなぎ先を入れ直す」。

## 6. 問題エディタ（PC のブラウザで）

1. `https://ozackdown0925-web.github.io/brain-dungeon/editor.html` を開く。
2. **GAS の URL** と**管理用の鍵**（記録の読み出し先.txt の「読み出し用の鍵」）を入れて「ひらく」。そのブラウザが覚える。
3. 左の一覧から問題を選ぶと、真ん中で直せて、右に子どもが見る画面が出る。「保存」でスプレッドシートに入る。
   - 画像は、真ん中の「問題の図」の欄にドラッグするか、クリックしてから Ctrl+V で貼り付け。
   - 「出題する」のチェックを外すと、その問題は出なくなる（消さずに休ませる）。
4. 鍵を入れ直すときは、右上の「鍵を入れ直す」。
   - 管理用の鍵は、問題を書きかえられる鍵。子どもの iPad では開かない。

## 7. あとで直したとき

`gas\` で `clasp push` → `clasp deploy -i <デプロイID> -d "メモ"`。
`setup` を実行し直すのは、新しいシートや鍵が増えたときだけ（何度実行しても、鍵は変わらない）。

## 暗証番号を忘れたとき・変えたいとき

スプレッドシートの「Brain Dungeon」→「保護者の暗証番号を入れる」で、新しい番号を入れ直す（前の番号はいらない）。

## 窓口の一覧（画面からは POST、Content-Type: text/plain、中身は JSON `{ key, action, ... }`）

| action | 鍵 | 中身 | 返事 |
|---|---|---|---|
| check | プレイヤー／管理 | | `role`（player / admin）、`player`（child / parent） |
| drillQuestions | プレイヤー／管理 | | `questions`（出題するものだけ） |
| image | プレイヤー／管理 | `id` | `src`（data URL） |
| history | プレイヤー／管理 | | `records`（そのプレイヤーの分だけ）、`player` |
| saveAnswer | プレイヤー／管理 | `record` | （そのプレイヤーの記録として保存） |
| loadGame | プレイヤー／管理 | | `data`（セーブの JSON 文字列。なければ null）、`savedAt`、`rev`（版） |
| saveGame | プレイヤー／管理 | `data`、`base`（持っている版）、`force`、`checkpoint`（区切りの名前）、`summary` | `rev`、`savedAt`。版がちがえば上書きせず `conflict: true` |
| checkpoints | プレイヤー／管理 | | `checkpoints`（最近の10回分、新しい順。`id`・`at`・`label`・`summary`） |
| loadCheckpoint | プレイヤー／管理 | `id` | `data` |
| logAdventure | プレイヤー／管理 | `entry`（`date`・`kind`・`floor`・`correct`・`subjects`・`note`） | |
| adventures | プレイヤー／管理 | | `adventures`（そのプレイヤーの分） |
| pinStatus | プレイヤー／管理 | | `set`（決めてあるか）、`locked`（受けつけない残り秒） |
| pinCheck | プレイヤー／管理 | `pin` | `match`、`locked` |
| sound | プレイヤー／管理 | `name`（例 michinarini.mp3） | `name`・`mime`・`size`・`updated`・`data`（base64）。ドライブの「Brain Dungeon の音（配布禁止の素材）」フォルダから |
| questions | 管理 | | `questions`（すべて） |
| saveQuestion | 管理 | `question` | `question` |
| deleteQuestion | 管理 | `id` | |
| uploadImage | 管理 | `dataUrl`, `name` | `id` |
| export | 管理 | `player`（省略すると child） | `records` |
| sounds | 管理 | | `sounds`（`name`・`size`・`updated`） |
| uploadSound | 管理 | `name`、`dataUrl` | `name`・`size`（同じ名前があれば、前のものはごみ箱へ） |
| deleteSound | 管理 | `name` | （ごみ箱へ） |
| import | 管理 | （今まで通り。upload.py 用） | |

- 返事は `{ ok: true, ... }` か `{ error: "…" }`（鍵がちがうと `forbidden`）。
- 読むだけのもの（check・drillQuestions・image・history）は GET `?action=…&key=…` でも使える。セーブと暗証番号は POST だけ。
- プレイヤーは鍵で決める。画面から player は送らない（管理用の鍵のときだけ `player` を指定できる。省略すると child）。
- `?action=export&key=…` は今まで通りの形で、子どもの記録だけを返す。`&player=parent` で保護者の分、`&player=all` で全員分（各行に `player` が付く）。
- 今までの `?action=export&key=…`・`?action=questions&key=…`・POST `action=import` は形を変えていない。
- 暗証番号は固定。スプレッドシートのメニューから入れ、ハッシュ（元にもどせない形）にしてスクリプトプロパティ `PARENT_PIN` に置く。画面からは確かめる（pinCheck）だけ。続けて5回まちがえると10分受けつけない。
- セーブは「セーブ」シートにプレイヤーごとに1行。大きいときは4万文字ずつ右の列へ分ける（どのかけらも「~」で始まる）。
