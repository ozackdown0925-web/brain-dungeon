# 使った素材と出どころ

公開リポジトリに置くので、自由に使ってよいもの（CC0 など）だけを使う。使ったら、ここに書く。

## 絵

- タイトル画面の絵：プログラムで1点ずつ描いたドット絵（`js/game/titleart.js`。素材は使っていない。16ビット時代のドット絵の雰囲気だけを目ざし、特定のゲームの絵やキャラはまねしない）。
- 仲間の絵：プログラムで描いたドット絵（`js/game/sprites.js`。16×24点、5職業×向き×コマ、髪の色8種、手に持つ武器）。
- 敵・地面・町・顔の絵：段階7-2 でプログラムで描く（2026-10-17 保護者と決定。素材集は使わない）。

## 音

- 音を鳴らすしくみ：`js/game/sound.js`。ファイルは `assets/sound/` に置く（まだない）。
- 使う予定の素材：NOT JAM MUSIC PACK 2（https://not-jam.itch.io/not-jam-music-pack-2 、CC0。BGM 15曲・効果音41個）。保護者がダウンロードして渡し、iPadOS 16 で鳴らせる mp3 にして置く。
