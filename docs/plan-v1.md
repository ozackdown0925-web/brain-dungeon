# 最初の版（森14階層）を作る計画

2026-10-17 作成。設計は `docs/game-design.md`（決まったこと）と `docs/draft.md`（数字のたたき台）。

## 前提

- ドリルの移行（ブランチ `claude/drill-migration-*`）が先に main に入ること。GAS の窓口（鍵・プレイヤー・記録）はそれを土台にする。ゲームの画面づくりは、それを待たずに偽の窓口で始められる。
- iPadOS 16.7 の Safari で動くこと。ビルドの道具は使わず、そのまま読める JavaScript（`?.`・`??` などは使わない）。
- 描画は **Canvas 2D を自分で書く**（ゲームのライブラリは使わない）。理由：iPadOS 16 で動くかを確実にできる、ファイルが小さい、ドット絵の表示を細かく決められる。
- 絵と音は無料で公開してよい素材（CC0 を優先）。出どころは `docs/credits.md`。素材が決まるまでは、図形の仮の絵で作り、あとで差しかえる。

## フォルダ

```
game.html            ゲームの入口（拠点・ダンジョン・知恵の試練・保護者画面）
js/game/
  core.js            ゲームの流れ（画面の切りかえ、時間、セーブの区切り）
  input.js           画面のボタン（iPad）とキーボード（PC）
  render.js          描画（ドット絵、文字、ふりがな）
  data/              職業・スキル・武器・敵・部屋の定義（たたき台の数字をここに）
  battle.js          攻撃・Wait Time・属性・状態異常・ダメージ
  dungeon.js         部屋のつなぎ方（seed）、鍵と扉、罠、宝箱、地図、出口
  base.js            拠点のメニュー（装備・お店・鍛冶屋・転職・倉庫・図鑑・遊び方）
  save.js            セーブ（GAS と iPad 内の控え）
  trial.js           ゲームの中の知恵の試練（drillcore.js を使う）
assets/              絵・音（無料素材のみ）
gas/Code.gs          セーブ・冒険の記録・設定・暗証番号の窓口を足す
```

## 作る順番

段階ごとに、保護者が PC と iPad で触って確かめてから次へ進む。

1. **土台**：game.html、画面の大きさ合わせ（iPad 横向き）、iPad のボタンと PC のキー、仮の部屋を1つ歩ける。
   - 確かめること：iPad で動きがなめらかか、ボタンが押しやすいか。
2. **戦いの手ざわり**：戦士1人、剣のふつうの攻撃と Wait Time、ゴブリン3種（剣士・槍兵・弓兵）、ダメージの数字、HP のバー、弱点の表示、会心。
   - 確かめること：約3回でたおせる、約20回当たると倒れる、という手ごたえ。
3. **パーティと職業**：3人の切りかえ（待ち時間・倒れたとき）、基本職5つ、スキル35個と使える条件、MP とクールタイム、状態異常、つる草の魔物。
4. **ダンジョン**：部屋の型と seed でのつなぎ方、鍵と扉、罠（隠れた罠も）、宝箱（正解数でレア度が変わる）、地図、出口、残り時間、14階層、ボス2体（大オオカミ・大木の魔物）、称号。
   - 3回に分けて確かめる（2026-10-17 決定）。**4-1 階層の形**：部屋の型と seed でのつなぎ方、出口、地図、残り時間、部屋ごとの敵（階層で強くなる）。**4-2 しかけ**：鍵と扉、罠、宝箱。**4-3 ボスと14階層**：大オオカミ・大木の魔物、称号、前後の短い文章。
   - 知恵の試練の正解数は、段階6までテスト用の設定の仮の値を使う。
5. **拠点とセーブ**：キャラクリ（名前・職業・顔）、拠点のメニュー（装備・お店・鍛冶屋・転職・倉庫・図鑑・遊び方）、GAS へのセーブ（階層に入るとき・終わったとき）と iPad 内の控え、途中で閉じたときの再開、セーブの復元（10回分）。
   - 3回に分けて確かめる（2026-10-17 決定）。**5-1 キャラクリと成長**：キャラクリ、経験値・レベル・熟練度★・スキルを覚える、拠点 → 出発 → 拠点にもどる。経験値と拾った物は、拠点にもどったときにまとめて入る。**5-2 拠点のメニュー**：装備・お店・鍛冶屋・転職・スキルのセット・倉庫・図鑑・遊び方。**5-3 セーブ**：再開、復元（10回分）。
   - セーブは、GAS ができるまで iPad の中（localStorage）だけ。GAS へ送るつなぎ口だけ用意する（2026-10-17 決定）。5-1 から、拠点にもどるたびに iPad の中に保存する。
6. **知恵の試練と1日の流れ**：神殿の飾りの試練画面、4問を解き終えると扉が開く、加護とクリア報酬、1日1回、インターネットがないときの表示、保護者画面（暗証番号、冒険の時間、休みの日、遊んだ記録、セーブの復元）と試しモード。
7. **仕上げと iPad での確認**：絵と音を素材に差しかえ、ふりがな、遊び方のページ、数字の調整。保護者が数日遊んでから子どもに渡す。ドリルだけの画面はこの時点で使わなくなる。
8. **上級職**（渡したあとすぐ）：基本職を極める（★7）のは約11日後なので、それまでに上級職15とそのスキルを入れる。

## 保護者にお願いすること

- GAS の更新（新しいバージョンでのデプロイ）。clasp が使えればこちらで反映する。
- GitHub に送る（push）・公開するときの了承。
