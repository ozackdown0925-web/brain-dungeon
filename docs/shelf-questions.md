# 書庫の知識の棚の問題の作り方（成績管理フォルダ側への申し送り）

2026-11-04。塾のふだんのプリント（理科・社会の確認テスト、国語の言語知識テストなど）を、書庫の「知識の棚」の問題にするときの決まり。
しくみは `docs/game-design.md` の 6.7。

**プリントは塾の教材なので、問題・答え・画像はこのリポジトリに置かない。** スプレッドシート（「問題」シート）とGoogleドライブ（画像のフォルダ）にだけ入れる。
取りこみは今のテストの問題と同じく、成績管理フォルダの `upload.py`（GAS の POST `action=import`）を使う。窓口の形は変えていない。

## 1問の形

今の問題と同じ JSON に、`"kind": "shelf"` を足す。これがあると知恵の試練には出ず、書庫の知識の棚だけに出る。

- **1つの問題＝一問一答1つ**。プリントの小問ごとに別の問題にする（理科の確認テストが10問なら、10個の問題）。覚えたかどうかを1問ずつ見るため。
  - ただし「①と②の名前を答える」のように、1つの問いに答えが2つあるものは、小問（`parts`）2つの1問にしてよい（2つとも○で正解）。
- **問いの文は `text` に書く**（画面の左に大きく出る）。小問の `prompt` は、答えが2つあるときの「①」「②」などだけにする。
- 図・地図がいる問題は、今のテストの問題と同じく、図を切り抜いて `images` に入れる（`img:名前`）。図がいらない問題は文だけでよい。
- ふりがな（ルビ）は入れなくてよい（問題の文にはふりがなをつけないきまり）。

| 項目 | 書き方 |
|---|---|
| `id` | 英数字。プリントと問題の番号から作る（例 `kt-sci-01-07`。同じ番号を2回使わない） |
| `kind` | `"shelf"`（かならず） |
| `subject` | `japanese`・`science`・`social`（算数はあとで「解き方を選ぶ」問題として足す。計算は入れない） |
| `unit` | 単元 |
| `source` | プリント名＋問題の番号。**最初の空白までがプリント名**（同じプリントの問題は同じにする）。例 `確認テスト上第1回理科 7`、`言語知識テスト上第1回 3(2)` |
| `text` | 問いの文（空らんは「（　）」や「＿＿」で） |
| `parts` | 答えの欄（下） |
| `explanation` | 解説があれば（なくてよい） |
| `enabled` | 出すなら `true` |

## 答えの欄（`parts` の `type`）

| プリントの問題 | `type` | 書き方 |
|---|---|---|
| 記号を選ぶ（ア〜エ） | `choice` | `options` に記号（例 `["ア","イ","ウ","エ"]`）、`answer` に正しい記号。選択肢の中身（「ア 東」など）は `text` か `prompt` に書く |
| 記号をすべて選ぶ | `multi` | `answer` に正しい記号の配列 |
| 言葉・用語・漢字・カタカナを答える | `recall` | `answer` に答え（1つ）。子どもは頭の中で答えてから「答えを見る」を押して、自分で○×をつける。別の言い方も正しいときは「〇〇（△△でもよい）」のように答えの中に書く |
| 数字だけを答える（理科の数など） | `number` | `answer` に数。`suffix` に単位 |

- 正答率（`rate`）は、プリントに書いてあれば入れてよい（今は使っていない）。
- 答えのページから答えを写すときに、記号と言葉を取りちがえないように、1問ずつたしかめる。

## 例（中身は作りもの。塾のプリントの問題ではない）

```json
{
  "id": "kt-soc-00-01",
  "kind": "shelf",
  "subject": "social",
  "unit": "日本の川",
  "source": "確認テスト見本社会 1",
  "text": "日本でいちばん長い川を何といいますか。",
  "parts": [{ "label": "", "prompt": "", "type": "recall", "answer": "信濃川" }],
  "enabled": true
}
```

```json
{
  "id": "kt-sci-00-02",
  "kind": "shelf",
  "subject": "science",
  "unit": "季節と生き物",
  "source": "確認テスト見本理科 2",
  "text": "ツバメが日本にやってくる季節はどれですか。\nア 春　イ 夏　ウ 秋　エ 冬",
  "parts": [{ "label": "", "prompt": "", "type": "choice", "options": ["ア", "イ", "ウ", "エ"], "answer": "ア" }],
  "enabled": true
}
```

## 記録

答えは「書庫の記録」シートに入る（知恵の試練の「記録」シートとは別）。成績の分析で知恵の試練の記録を読むところは変わらない。
棚の記録は管理用の鍵で `action=shelfExport`（`player` を省くと子どもの分）で読める。
