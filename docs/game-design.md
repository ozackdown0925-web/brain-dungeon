# Brain Dungeon ゲーム設計メモ

保護者の開発案（2026-10-17）をもとに、決まったことと検討中のことを分けて書く。
**決定**＝保護者が決めたこと、**検討中**＝案はあるがまだ決まっていないこと、**未定**＝これから決めること。

## 1. ジャンルとイメージ（決定）

- ハクスラ系のアクションRPG。塾のドリル（毎日4問ドリルと同じ問題）と組み合わせる。
- 見下ろし型の、昔なつかしいドット絵のアクションRPG（絵のイメージは聖剣伝説2など。雰囲気の参考で、キャラや素材は独自に用意する）。
- **絵の素材は、無料で公開リポジトリに置いてよいもの**（CC0 など）を使う。使った素材は出どころとライセンスを `docs/credits.md` に書く。
- 敵の攻撃を必死でかわすようなアクション性は求めない。

## 2. 全体の流れ（決定）

1. 冒険の準備
2. 出発
3. ドリルを解く（結果によって、成功報酬や宝箱の中身などが変わる）
4. ダンジョン探索（5分程度）
5. クリア

- 1日に1階層ずつ進む（同じ階層にもう一度挑戦してもよい）。
- **出発できるのは1日1回**。その1回で、新しい階層に進むか、前の階層にもう一度挑戦するかを選ぶ。
- **7階層ごとにボス戦**。曜日ではなく階層で数える（休んだ日があれば、その分ボスが先になる）。ダンジョンの階層は7の倍数（3.5を参照）。
- 流れ3のドリルは**「毎日4問」そのもの**。結果はドリルの記録に入る。
  - 教科は今のまま、算数・国語・理科・社会を1問ずつ。
  - 出題の順：正解した回数が少ない問題が先（正解すると大きく後回しになる）。同じ回数なら、テストでまちがえた問題 → 正答率の高い問題の順。**3日後の復習はやめる**。まちがえた問題は優先度が下がらないので、すぐまた出る（正解するまで出つづける）。
  - ドリルの名前は変える（新しい名前は未定）。
- **4問を解き終えないとダンジョンに入れない**（正解しなくてもよい。解き終えれば扉が開く）。
- **4問の結果で変わるもの**
  - 宝箱のレア度：正解が多いほど、ダンジョンの宝箱からよい装備が出る。
  - その日の加護：正解した教科ごとに、その日の冒険でだけ効くバフがつく。**教科ごとに決まった加護**（決定）。たたき台：算数→物攻、国語→魔攻、理科→物防・魔防、社会→HP・MP（中身はあとで調整）。
  - クリア報酬：クリアしたときの経験値やお金が増える。

## 3. パーティと操作（決定）

- プレイヤーキャラは3人。切りかえながら進む（選んでいないキャラは待機）。
- **待機中のキャラは画面にいない**。戦うのは選んだ1人だけで、切りかえるとその場で入れかわる。待機中は攻撃されない。
- 戦闘不能になったキャラは、ステージクリアまで使えない（アイテムで復活できる）。
- 戦闘中のボタン：十字キー、攻撃、スキル1、スキル2、スキル3、キャラ切りかえ、メニュー。

- **3人は自分で作る**：名前と最初の職業を選んで作る。

## 3.5 ワールドマップとダンジョン（決定）

- **ワールドマップがいくつかある**。マップごとに特徴を持たせる（例：属性。火のマップには火の敵が多い、など）。
- **各マップに拠点が1つ、ダンジョンが数個**。
- ダンジョンの階層の数はダンジョンごとにちがい、**7の倍数**（7・14・21…）。
- **そのマップのダンジョンを全部攻略すると、次のマップが開く**。
- マップの中のダンジョンには**好きな順に入れる**。その日にどこへ行くかを選ぶ。進み具合はダンジョンごとに残る。
- 7階層ごとのボスは中ボス。**いちばん下の階層のボス（主）をたおしたら、そのダンジョンは攻略**。
- ボスの階層で負けたら、次の日も**そのボスの階層から**。前の階層にもどって強くなってから挑んでもよい。
- ダンジョンの形：作りこんだ部屋を用意し、入るたびにつなぎ方だけ変える。ボスの階層は、決まった形のマップ。

## 3.6 1回の冒険の終わり方（決定）

- **出口にたどり着いたらクリア**。寄り道すると宝箱がある。
- **約5分の時間切れ、または3人とも戦闘不能**になったら、その日の冒険は終わり。拾った装備と経験値は持ち帰れるが、階層は進まない。

## 3.7 拠点でできること（決定）

- 装備の入れかえ（3人に付けかえる、いらない装備を売る）
- お店（回復薬・復活薬・装備を買う）
- 鍛冶屋（素材とお金で装備を強くする・作る）
- 転職の神殿（熟練度がたまったら職業を変える）

## 3.8 最初の版の範囲（決定）

- **マップ1つ・ダンジョン1つ（7階層）と拠点**。早く遊び始めて、お子さんが楽しんでいるかを確かめてから広げる。

## 4. 戦闘のしくみ

### 攻撃のテンポ（決定）
- 1回攻撃すると、武器の Wait Time のあいだは次の攻撃ができない（たまるまで待つ）。そのあいだも移動して位置をとるのは自由。
- 敵の攻撃を必死でかわすゲームにはしない（敵の攻撃は予告を長めにする、など）。

（以下は検討中）

### 攻撃属性
- 斬・刺・打・火・水・草・光・闇
- 敵ごとに弱点・半減・無効を設定する。
- 攻撃属性は武器ごと、またはスキルごとに設定する。

### 状態異常
| 状態 | 効果 | 治り方 |
|---|---|---|
| 毒 | 一定間隔でダメージ | 時間で回復 |
| 痺（しびれ） | 一定時間移動できない | 時間で回復 |
| 眠 | 一定時間行動できない | 時間、またはダメージを受けると回復 |
| 戦闘不能 | ステージ終了までキャラを選べない | アイテムで復活 |

### 基礎パラメーター → 戦闘パラメーター
| 基礎 | 影響する戦闘パラメーター |
|---|---|
| 筋力 | 物攻、物防 |
| 体力 | HP |
| 魔力 | 魔攻、魔防 |
| 知力 | MP |

- HP：0で戦闘不能。MP：0でスキルが使えない。
- 物攻・物防・魔攻・魔防：物理・魔法の攻撃力と防御力。

## 5. 装備（検討中）

### 武器
- **土台は決まっていて、追加はランダム**（決定）：武器ごとの種類・基本の強さ・攻撃属性・Wait Time は決まっている。拾うたびに、バフ・デバフだけがランダムにつく（レア度が高いほどバフが多く、デバフが少ない、など）。
- 武器の種類（下の表から1つ）
- バフ1・2：選んだ戦闘パラメーターにプラス
- デバフ1・2：選んだ戦闘パラメーターにマイナス
- 攻撃属性：1つ
- Wait Time：次の行動までの待ち時間

| 武器 | 射程 | 範囲 |
|---|---|---|
| 剣 | 近 | 小 |
| 大剣 | 近 | 中 |
| 槍 | 中 | 小 |
| 弓 | 遠 | 小 |
| 斧 | 近 | 中 |
| 拳 | 近 | 小 |
| 杖 | 近 | 小 |

### 防具
- 軽装備・重装備・魔法装備。職業ごとに装備できるものが違う。

## 6. 職業

- **基本職は戦士・魔術師・狩人（弓）の3つ**（決定）。転職で上級職が増える。
- **熟練度は職業ごと**（決定）：その職業で戦うほど上がり、スキルを覚えたり、転職できるようになったりする。
- **レベルはキャラごと**（決定）。レベルが上がるとき、今の職業によって筋力・体力・魔力・知力の伸び方が変わる（これが成長パラメーター1〜4）。転職してもレベルはそのまま。
- **スキル**（決定）：熟練度が上がるとスキルを覚える。拠点で、覚えたスキルの中から3つをスキル1〜3にセットする。転職しても、前の職業で覚えたスキルを使える。
- 項目（検討中）：職業名、装備できる武器、装備できる防具、成長パラメーター1〜4、熟練度、転職の条件。
