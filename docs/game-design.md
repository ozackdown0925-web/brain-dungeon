# Brain Dungeon ゲーム設計メモ

保護者の開発案（2026-10-17）をもとに、決まったことと検討中のことを分けて書く。
**決定**＝保護者が決めたこと、**検討中**＝案はあるがまだ決まっていないこと、**未定**＝これから決めること。

## 1. ジャンルとイメージ（決定）

- **画面の文字は、ふつうの漢字にふりがなをつける**（小4が読めるように）。
- **初めての人への説明は、拠点の「遊び方」のページ**に置く。

- ハクスラ系のアクションRPG。塾のドリル（毎日4問ドリルと同じ問題）と組み合わせる。
- 見下ろし型の、昔なつかしいドット絵のアクションRPG（絵のイメージは聖剣伝説2など。雰囲気の参考で、キャラや素材は独自に用意する）。
- **絵の素材は、無料で公開リポジトリに置いてよいもの**（CC0 など）を使う。使った素材は出どころとライセンスを `docs/credits.md` に書く。
- **音はBGMも効果音も入れる**（決定）。絵と同じく、無料で公開してよい素材を使う。設定で消せる。
- **物語はあっさり**（決定）：マップやダンジョンの始まりと、ボスの前後に短い文章が出るくらい。
- 敵の攻撃を必死でかわすようなアクション性は求めない。

## 2. 全体の流れ（決定）

1. 冒険の準備
2. 出発
3. ドリルを解く（結果によって、成功報酬や宝箱の中身などが変わる）
4. ダンジョン探索（5分程度）
5. クリア

- 1日に1階層ずつ進む（同じ階層にもう一度挑戦してもよい）。
- **出発できるのは1日1回**。その1回で、新しい階層に進むか、前の階層にもう一度挑戦するかを選ぶ。
- もう一度挑戦した階層の報酬は、**新しい階層と同じしくみ**（浅い階層なので、もともと敵も報酬も弱め）。
- **冒険の時間は保護者が設定する**（はじめは5分）。
- **7階層ごとにボス戦**。曜日ではなく階層で数える（休んだ日があれば、その分ボスが先になる）。ダンジョンの階層は7の倍数（3.5を参照）。
- 流れ3のドリルは**「毎日4問」そのもの**。結果はドリルの記録に入る。
  - 教科は今のまま、算数・国語・理科・社会を1問ずつ。
  - 出題の順：正解した回数が少ない問題が先（正解すると大きく後回しになる）。同じ回数なら、テストでまちがえた問題 → 正答率の高い問題の順。**3日後の復習はやめる**。まちがえた問題は優先度が下がらないので、すぐまた出る（正解するまで出つづける）。
  - **ドリルの新しい名前は「知恵の試練」**（決定）。
- **知恵の試練はゲームの中だけで解く**（決定）。ゲームができあがったら、ドリルだけの画面は使わなくなる（それまではドリルだけの画面を使う）。
- **ゲームの中の知恵の試練は、ゲーム風の飾り**（決定）。解き方は今のドリルと同じ（図への書きこみ、メモもある）で、まわりの飾りだけ神殿などにする。
- **4問を解き終えないとダンジョンに入れない**（正解しなくてもよい。解き終えれば扉が開く）。
- **4問の結果で変わるもの**
  - 宝箱のレア度：正解が多いほど、ダンジョンの宝箱からよい装備が出る。
  - その日の加護：正解した教科ごとに、その日の冒険でだけ効くバフがつく。**教科ごとに決まった加護**（決定）。算数→物攻、国語→魔攻、理科→物防・魔防、社会→HP・MP、それぞれ＋10%（決定）。
  - クリア報酬：クリアしたときの経験値やお金が増える。
  - **増え方は正解ごとに少しずつ**（決定）：0問でもふつうの報酬がもらえ、正解1問ごとに少しずつ上がる（たたき台：クリア報酬は1問ごとに+25%、宝箱のレア度も1問ごとに少し上がる）。数字は遊んでみてから調整する。

## 3. パーティと操作（決定）

- プレイヤーキャラは3人。切りかえながら進む（選んでいないキャラは待機）。
- **切りかえたあと数秒は、もう一度切りかえられない**（決定）。
- **待機中のキャラは画面にいない**。戦うのは選んだ1人だけで、切りかえるとその場で入れかわる。待機中は攻撃されない。
- 戦闘不能になったキャラは、ステージクリアまで使えない（アイテムで復活できる）。
- **今のキャラが戦闘不能になったら、ゲームが止まり、次に使うキャラを自分で選ぶ**（決定）。
- **メニューを開いているあいだは、敵も時間も止まる**（決定）。
- **経験値と熟練度は3人とも同じだけ入る**（決定）。だれがたおしても全員に入る（戦闘不能のキャラには入らない）。
- **回復**（決定）：毎日の出発のときにHP・MPは全快。冒険中のHPはアイテムやスキルで回復し、MPは少しずつ自然に回復する。
- 戦闘中のボタン：十字キー、攻撃、スキル1、スキル2、スキル3、キャラ切りかえ、メニュー。
- **iPad と PC の両方で遊ぶ**（決定）。iPad は画面のボタン（左に十字キー、右に攻撃・スキル3つ・切りかえ・メニュー）、PC はキーボード。iPad は横向きを想定（検討中）。

- **3人は自分で作る**（キャラクリ）：ゲームを一番最初に始めるときに、3人の名前・最初の職業・顔グラフィックを選ぶ。プレイヤー（子ども・保護者）ごとに別々に作る。**作れるのは3人だけ**（控えはない）。**3人が同じ職業でもよい**（決定）。
- **ダンジョンの中の見た目（ドット絵）は職業で決まる**（決定）。職業ごとに1つ。転職すると見た目も変わる。
- **顔グラフィックは複数の中から選べる**（できれば。無料で公開してよい素材が見つかる範囲で）。メニュー・ステータス・会話の画面に出る。職業を変えても顔は変わらない。
  - **顔の絵は、段階7でキャラ・敵・地面の絵といっしょに決める**（2026-10-17 決定）。それまでは仮の顔（8種類）。CC0 の候補：OpenGameArt「rpg portraits」（Buch）、itch.io「Pixel art portrait pack」（Loregret）、OpenGameArt「32 x 32 portraits」（Seafood5040）。

## 3.5 ワールドマップとダンジョン（決定）

- **ワールドマップがいくつかある**。マップごとに特徴を持たせる（例：属性。火のマップには火の敵が多い、など）。
- **各マップに拠点が1つ、ダンジョンが数個**。
- ダンジョンの階層の数はダンジョンごとにちがい、**7の倍数**（7・14・21…）。
- **そのマップのダンジョンを全部攻略すると、次のマップが開く**。
- マップの中のダンジョンには**好きな順に入れる**。その日にどこへ行くかを選ぶ。進み具合はダンジョンごとに残る。
- 7階層ごとのボスは中ボス。**いちばん下の階層のボス（主）をたおしたら、そのダンジョンは攻略**。
- ボスの階層の時間も、ふつうの階層と同じ（保護者の設定）。
- ボスの階層で負けたら、次の日も**そのボスの階層から**。前の階層にもどって強くなってから挑んでもよい。
- ダンジョンの形：作りこんだ部屋を用意し、入るたびにつなぎ方だけ変える。ボスの階層は、決まった形のマップ。
- **地図は最初から全部見える**（決定）。出口の位置も分かる。
- **部屋の大きさは画面1〜2枚分**（2026-10-17 決定）。1階層は約6部屋（入口から出口まで5部屋＋寄り道1〜2部屋）。森の部屋の型は10個（`js/game/rooms.js`）。部屋のはしの道を通ると、となりの部屋へ移る。
- **地図は画面の右上に小さく出し、メニューで大きく見られる**（2026-10-17 決定）。
- **宝箱は少なめで豪華**（決定）：1階層に2〜3個。中身はいつも装備1つ＋素材＋ゴールド。寄り道する価値がある。敵のドロップは少なめ。
- **敵の強さは階層で決まり、レベルが高すぎるときだけ少し強くなる**（決定）：経験値をかせぐと少しだけ楽になる。装備・スキル・職業で強くなるほうが効く。
- **戦い以外のしかけは「鍵と扉」と「罠」**（決定）。鍵を見つけると開く扉の奥に、よい宝箱がある。罠は毒の沼、落とし穴など。**一部の罠は踏むまで見えない**（決定）。一度踏むと地図に出る。
  - **鍵は、どこかの部屋に落ちている**（2026-10-17 決定）。鍵のかかった扉は1階層に1つで、寄り道の部屋の入口にある。地図で鍵・宝箱・見つけた罠の場所が分かる。
  - **鍵の部屋の宝箱は、レア以上が必ず出る**（2026-10-17 決定）。正解数でさらによくなる。
  - **落とし穴に落ちると、少しダメージ（最大HPの10%。これで倒れることはない）を受け、その部屋の入口にもどされる**（2026-10-17 決定）。毒の沼に入ると毒になる。
- **ボスをたおすと称号・メダルがもらえる**（決定）。強さには関係のない、自慢できる印。
- **ボスの階層の形**（2026-10-17 決定）：入口の部屋 → 敵のいる部屋 → 広いボスの部屋。ボスの部屋に入ると短い文章が出て、つるが道をふさぐ。
- **ボスをたおすと、ごほうびの宝箱（レア以上）2つと出口が現れる**（2026-10-17 決定）。宝箱を開けてから出口へ進む。
- **ボスの前後の短い文章は、Claude が仮の文を書き、保護者があとで直す**（2026-10-17 決定）。文は `js/game/data.js` の `BOSSES`。

## 3.6 1回の冒険の終わり方（決定）

- **出口にたどり着いたらクリア**。寄り道すると宝箱がある。
- **冒険の時間は、ダンジョンに入ってから数える**（決定）。残り時間は画面の上にいつも表示し、残り1分で色が変わる。知恵の試練を解く時間は入らない。
- **途中でアプリを閉じたり iPad がスリープしたりしても、その日のうちなら残り時間で続きから遊べる**（決定）。拾った物と経験値はそのまま。**再開はその階層の入口から**（決定）：部屋のつなぎ方は同じ。たおした敵は元に戻るが、開けた宝箱は開いたまま。
- **時間切れ（保護者の設定、はじめは5分）、または3人とも戦闘不能**になったら、その日の冒険は終わり。拾った装備と経験値は持ち帰れるが、階層は進まない。

## 3.7 拠点でできること（決定）

- **拠点はメニュー画面**：町の絵の上に「お店」「鍛冶屋」などのボタンを並べる。
- **ワールドマップは地図で選ぶ**：地図の上の拠点やダンジョンをタップして選ぶ。


- 装備の入れかえ（3人に付けかえる、いらない装備を売る）
- お店：回復薬・復活薬、状態異常の薬（毒消しなど）、ふつうの装備（ノーマル）を売る。MPの薬は売らない（MPは自然に回復する）。
- 鍛冶屋（素材とお金で装備を強くする・作る）。**強化は必ず成功する**。それとは別に、素材を使ってランダムなバフ・デバフを引き直せる（決定）。
- 転職の神殿（熟練度がたまったら職業を変える）
- **図鑑**（決定）：モンスター図鑑（たたかった敵、たおした数、試した属性の効き方）、装備図鑑（手に入れた装備の種類）、称号・メダルの棚
- **続けて遊んだ日数のごほうびは入れない**（決定）

## 3.8 最初の版の範囲（決定）

- **マップ1つ・ダンジョン1つ（14階層：7階層目に中ボス、14階層目に主）と拠点**。早く遊び始めて、お子さんが楽しんでいるかを確かめてから広げる。
- **森の主をたおしたあとは、次のマップを作るまで好きな階層を周回できる**（1日1回のまま）。装備集めや転職を続ける。
- **最初のマップは森（草属性）**。草属性の敵が多く、火が弱点。
- **森の主（14階層目）は大木の魔物**：古い大木が動き出したもの。根や枝で攻撃し、火が弱点。**7階層目の中ボスは大オオカミ**（群れの長。速い突進と、小さなオオカミを呼ぶ）。
- **森のふつうの敵**（決定）：ゴブリンの剣士（近距離。盾で守りながら近づく）、ゴブリンの槍兵（中距離。長い槍で突く）、ゴブリンの弓兵（遠距離）。ゴブリンの部隊として一緒に出る。ゴブリンは属性なし。
- **草属性の敵も少しまぜる**（決定）：つる草の魔物（中距離。つるをのばしてしびれさせる）。
- **1部屋の敵は4〜6体（平均5体）。入口の部屋にもいる**（2026-10-17 変更。前は2〜4体）。敵1体あたりのごほうびを減らして、1階層でもらえる経験値・ゴールド・素材の合計は前と同じにする。
- **部屋の敵を全滅させると、その部屋では速く歩ける**（1.5倍。2026-10-17 決定）。探索しやすいように。
- **ふつうの敵が落とすのはゴールドと素材だけ**（決定）。装備は宝箱・ボス・お店・鍛冶屋から。
- **敵の雰囲気はかっこいい系**（オオカミ、騎士、ドラゴンなど）。

## 3.9 お金と素材（決定）

- **お金の名前はゴールド（G）**。
- **鍛冶の素材は少なく、2〜3種類**（決定）（例：鉄、魔石）。
- いらない装備は、**売る（ゴールド）か分解する（鍛冶の素材）かを選べる**。

- 敵をたおす、宝箱を開ける、いらない装備を売る（分解する）と手に入る。ドリルの正解でしか手に入らない特別な素材は作らない（ドリルの結果は宝箱のレア度・加護・クリア報酬に効く）。

## 4. 戦闘のしくみ

### 攻撃のテンポ（決定）
- 1回攻撃すると、武器の Wait Time のあいだは次の攻撃ができない（たまるまで待つ）。そのあいだも移動して位置をとるのは自由。
- 敵の攻撃を必死でかわすゲームにはしない。**ふつうの攻撃は当たるものとして設計する**（決定）。かわすことを求めるのは、ボスなどのとても大きなダメージの攻撃だけ。その攻撃は1.5〜2秒前に地面などで予告する（決定）。
- **敵の攻撃に種類を持たせる**（決定）：近距離・中距離・遠距離。
- **スキルはMPを使い、使ったあとしばらく使えない**（クールタイム）（決定）。

（以下は検討中）

### 攻撃属性
- 斬・刺・打・火・水・草・光・闇
- 敵ごとに弱点・半減・無効を設定する。
- **物理の属性（斬・刺・打）は武器の種類で決まる**（決定）。火・水・草・光・闇は、魔法・スキル・特別な武器につく。
- **最初の版は、物理の3つ（斬・刺・打）と、魔法の属性2つくらい**（決定）。たたき台：火と水（森の敵は草で、火が弱点）。
- **ダメージの数字を表示する**（決定）：敵の上に数字が飛び出る。
- **敵のHPはバーで見える**（決定）：ふつうの敵は頭の上、ボスは画面の上に大きく。
- **会心の一撃（クリティカル）を入れる**（決定）。ときどき大きなダメージが出る。装備のバフで出やすくできる。
- **弱点は攻撃したときに表示する**（決定）：弱点をつくと「弱点！」、半減なら「いまひとつ」、効かないと「無効」と文字が出る。

### 状態異常
| 状態 | 効果 | 治り方 |
|---|---|---|
| 毒 | 一定間隔でダメージ | 時間で回復 |
| 痺（しびれ） | 一定時間移動できない | 時間で回復 |
| 眠 | 一定時間行動できない | 時間、またはダメージを受けると回復 |
| 戦闘不能 | ステージ終了までキャラを選べない | アイテムで復活 |

- **毒・痺・眠は、時間のほかにアイテムとスキルでも治せる**（決定）。キャラを切りかえても治らない。
- **こちらからも敵に状態異常をかけられる**（決定）：スキルや特別な武器で。ボスには効きにくい。

### 基礎パラメーター → 戦闘パラメーター
| 基礎 | 影響する戦闘パラメーター |
|---|---|
| 筋力 | 物攻、物防 |
| 体力 | HP |
| 魔力 | 魔攻、魔防 |
| 知力 | MP |

- HP：0で戦闘不能。MP：0でスキルが使えない。
- 物攻・物防・魔攻・魔防：物理・魔法の攻撃力と防御力。

## 5. 装備

- **部位は武器・防具・アクセサリの3つ**（決定）。アクセサリは職業に関係なくつけられる。効果は4種類（決定）：状態異常を防ぐ、属性に強くなる、能力が上がる、特別な効果（会心が出やすい、MPの回復が速い、Wait Time が短い など）。
- **レア度は4段階**（決定）：ノーマル・レア・エピック・レジェンド。色で見分ける。
- **基本職の装備**（決定）：戦士＝剣・大剣・斧／重装備、魔術師＝杖／魔法装備、狩人＝弓／軽装備。槍は上級職（騎士）で使える。拳は基本職の武術家が使う。

（以下は検討中）

### 武器
- **土台は決まっていて、追加はランダム**（決定）：武器ごとの種類・基本の強さ・攻撃属性・Wait Time は決まっている。拾うたびに、バフ・デバフだけがランダムにつく（レア度が高いほどバフが多く、デバフが少ない、など）。
- 武器の種類（下の表から1つ）
- バフ1・2：選んだ戦闘パラメーターにプラス
- デバフ1・2：選んだ戦闘パラメーターにマイナス
- 攻撃属性：1つ
- Wait Time：次の行動までの待ち時間

| 武器 | 射程 | 範囲 |
|---|---|---|
| 剣 | 近 | 小 |
| 大剣 | 近 | 中 |
| 槍 | 中 | 小 |
| 弓 | 遠 | 小 |
| 斧 | 近 | 中 |
| 拳 | 近 | 小 |
| 杖 | 中 | 小 |

- **魔術師のふつうの攻撃は、小さな魔法弾**（決定）：少し離れた敵に飛ばす。MPは使わない。強い魔法はスキルで使う。
- **杖のふつうの攻撃は職業で変える**（決定）：魔術師の系統の職なら魔法弾、それ以外の職（僧侶など）なら近くをたたく（打）。
- **レンジャーだけは武器を2つ（剣と弓）装備できる**（決定）。持ちかえは敵との距離で自動（近いと剣、遠いと弓）。
- **狩人の矢は数の制限なし**（決定）。Wait Time だけかかる。

### 持ち物（決定）
- 冒険中に持てる数には上限がある。拠点に倉庫があり、たくさんしまっておける。
- **装備のつけかえは拠点でだけ**できる。冒険中は拾うだけ（出発前の準備が大事になる）。

### 防具
- 軽装備・重装備・魔法装備。職業ごとに装備できるものが違う。

## 6. 職業

- **基本職は5つ**（決定）：戦士・魔術師・狩人（弓）・武術家（拳）・僧侶。
  - 僧侶の回復は、ほかの職より回復量が多く、待機中のキャラも含めて全員を回復できる。
  - 装備：武術家＝拳／軽装備、僧侶＝杖（打属性でたたく）／魔法装備。
- **転職**（決定）：基本職どうしは拠点の転職の神殿でいつでも変えられる。熟練度がたまると上級職が開く。
- **上級職は2種類ある**（決定）：1つの職からの一本道の上級職と、2つの職の組み合わせの上級職。さらにその先の職業も考える。
  - 一本道：戦士 → 騎士（槍も使える、守りが強い）、魔術師 → 黒魔道士（攻撃魔法・闇・状態異常）、狩人 → 狙撃手（遠くから強い一発、会心が出やすい）。武術家 → 修行僧（拳で戦いながら、自分も回復できる）、僧侶 → 白魔道士（回復と、仲間を強くする魔法）。
  - 組み合わせ（9つ）：魔法剣士（戦士＋魔術師）、レンジャー（戦士＋狩人）、精霊弓使い（魔術師＋狩人）、剣闘士（戦士＋武術家）、気功師（魔術師＋武術家）、忍者（狩人＋武術家）、拳聖（僧侶＋武術家）、聖騎士（戦士＋僧侶）、賢者（魔術師＋僧侶）。狩人＋僧侶の組み合わせは今は入れない。
  - **さらに先は、一本道の最上級職**（決定）：上級職からさらに一段上がる（例：騎士 → 聖剣士）。一覧と条件は未定。
  - **開く条件は熟練度だけ**（決定）：一本道はもとの職が★7（極めたとき）、組み合わせは2つの職がどちらも★5以上。
- **熟練度は★の数で見せる**（決定）（★☆☆☆☆ のように段階で）。★が増えるごとに、**決まった順に**スキルを覚える。
  - **1つ目のスキルは、その職業になったときから使える**（2026-10-17 決定。Lv1 でも職業の差が出るように）。★k のスキルは ★(k−1) で覚え、★7 は「極めた」印（上級職が開く）。
- **熟練度は職業ごと**（決定）：その職業で戦うほど上がり、スキルを覚えたり、転職できるようになったりする。
- **レベルはキャラごと**（決定）。レベルが上がるとき、今の職業によって筋力・体力・魔力・知力の伸び方が変わる（これが成長パラメーター1〜4）。転職してもレベルはそのまま。**伸びは自動**で、能力のポイントを自分で振ることはない（決定）。
- **回復のスキルは、どの職にも少しある**（決定）：自分を少し回復する弱いスキル。
- **基本職はそれぞれ6〜8つのスキルを覚える**（決定）。決まっているスキル：戦士＝回転ぎり（まわりの敵をまとめて斬る）、魔術師＝ファイア（火の玉、火属性）、狩人＝三本撃ち（矢を扇の形に3本）。残りはたたき台で提案する。
- **スキル**（決定）：熟練度が上がるとスキルを覚える。拠点で、覚えたスキルの中から3つをスキル1〜3にセットする。
- **スキルごとに「使える条件」をつける**（決定、自由すぎないようにするため）：
  - 条件は職業や装備している武器など。例：三本撃ち＝弓を装備しているとき、回転ぎり＝剣・大剣・斧を装備しているとき、ファイア＝魔術師の系統の職（魔術師・黒魔道士・魔法剣士など）のとき。
  - **武器を使うスキルは、その武器を装備しているときだけ使える**。魔法や回復のスキルは武器に関係しない。
  - **条件に合わないスキルはセットできない**（決定）。転職しても覚えたスキルは消えないが、今の職業と装備で条件に合うものだけをセットできる。
  - 拠点で職業や武器を変えて、セットしていたスキルが条件に合わなくなったら、そのスキルは外れる（外れたことを知らせる）。
  - ダンジョンの中では装備も職業も変えられないので、どのスキルを持っていくかは拠点での準備で決まる。
  - スキルごとの条件は、スキルの一覧と一緒に決める。
- 項目（検討中）：職業名、装備できる武器、装備できる防具、成長パラメーター1〜4、熟練度、転職の条件。

## 6.5 プレイヤーと保護者画面（決定）

- **インターネットにつながらないときは遊べない**（「インターネットにつないでね」と出す）。記録とセーブがいつもそろうようにするため。

- **プレイヤーは2人：子どもと保護者**。**端末ごとに1人**（子どもの iPad は子どもだけ。保護者は自分の端末で遊ぶ）。保護者も自分で遊んで、手ごたえを確かめる。
  - セーブデータは別々に持つ。
  - 知恵の試練の記録（正解・まちがい、正答率）も別々に持つ。問題とスタート（テストでまちがえた問題・早稲アカの正答率）は同じ。
  - 保護者の記録は、成績の分析（成績管理フォルダ）に混ぜない。
  - 保護者はふだん子どもと同じ決まり（1日1回、4問を解いてから）で遊ぶ。加えて**試しモード**が使える：回数や時間の制限なしで好きな階層を試せる。試しモードの結果は記録にもセーブにも残らない。
- **保護者画面は暗証番号で守る**（決定）。子どもの iPad でも、暗証番号を入れれば開ける。暗証番号は GAS 側で確かめる（画面のコードには置かない）。
- 保護者画面でできること
  - 冒険の時間の設定（はじめは5分）
  - 遊んだ記録を見る（いつ、どのダンジョンの何階層に行き、クリアしたか）
  - ゲームを休みにする（テスト前などに日を決めてダンジョンを閉じる。知恵の試練だけはできる）
  - セーブの復元（うっかり消したときなどに、前のセーブに戻す）。**最近の10回分**を残す。
