## 1. ジャンルとイメージ（決定）

- **画面の文字は、ふつうの漢字にふりがなをつける**（小4が読めるように）。
  - 7-3 で作った（2026-10-18）：小4までに習わない漢字（学年別漢字配当表の642字にない漢字）に、ルビでふりがなをつける。読みは辞書（`js/game/furigana.js` の WORDS）に**言葉ごと**にまとめ、画面に文字が出たときに自動でつける。**ふりがなは言葉全体につける**（例「経験値」の上に「けいけんち」。2026-10-18 保護者の希望。1文字だけに出ると読みにくいため）。「移す」のような漢字＋ひらがなの言葉は漢字の部分だけ。辞書で決まらない読みは文の中に `{漢字|よみ}` と書く。キャンバスの文字（ダンジョンの中、町と地図の名前の札）にもつける。保護者画面・つなぎ先の画面・テスト用の設定・知恵の試練の問いと答えにはつけない（`data-noruby`）。
- **画面の文の言い方**（2026-10-18）：「〜だよ」「〜してね」のような子どもに話しかける言い方はしない。ふつうの言い切り（「建物を押すと開く」）か、お願いのときは「〜してください」。
- **初めての人への説明は、拠点の「遊び方」のページ**に置く。
  - 7-3 で書き直した（2026-10-18）：1日の流れ・知恵の試練・そうさ・たたかい・ダンジョン・装備と鍛冶屋・拠点・そだてる。文は `js/game/town.js` の HELP（保護者があとで直す）。
- **ロード画面とTips**（2026-10-18 保護者の案）：ダンジョンに入るとき（知恵の試練のあと）と、拠点に帰るときに出す。Tips（`js/game/loading.js` の TIPS）を1つ出し、**2秒たったら自動で次へ**（タップで飛ばさない）。冒険の時間はダンジョンに入ってから数える。
- **帰るときの順番**（2026-10-18 保護者の案）：ダンジョンの結果 →「つづける」→ レベルアップ・熟練度・覚えたスキルを**1行ずつタップで**出す → ロード画面 → 拠点。持ち帰った物と経験値は「つづける」を押したときに受け取る（このあと閉じても、もらいそこねない）。

- ハクスラ系のアクションRPG。塾のドリル（毎日4問ドリルと同じ問題）と組み合わせる。
- 見下ろし型の、昔なつかしいドット絵のアクションRPG（絵のイメージは聖剣伝説2など。雰囲気の参考で、キャラや素材は独自に用意する）。
- **絵の素材は、無料で公開リポジトリに置いてよいもの**（CC0 など）を使う。使った素材は出どころとライセンスを `docs/credits.md` に書く。
- **音はBGMも効果音も入れる**（決定）。絵と同じく、無料で公開してよい素材を使う。設定で消せる。
- **物語はあっさり**（決定）：マップやダンジョンの始まりと、ボスの前後に短い文章が出るくらい。
  - **全体の物語**（2026-10-17 保護者の案）：魔王が世界を征服しようとしていて、主人公たちは魔王をたおすために旅をする、くらいのうすめの物語。はじめに開く画面（タイトル画面）に、1枚の絵と短い説明の文を出す。絵と文の仕上げは段階7。（7-1 で作った：絵はプログラムで描いた夜の魔王の城と3人のなかま。「はじめる」でつなぎ先・拠点へ。BGM・効果音のオン・オフもここと拠点・メニューにある）
- 敵の攻撃を必死でかわすようなアクション性は求めない。

## 2. 全体の流れ（決定）

1. 冒険の準備
2. 出発
3. ドリルを解く（結果によって、成功報酬や宝箱の中身などが変わる）
4. ダンジョン探索（5分程度）
5. クリア

- 1日に1階層ずつ進む（同じ階層にもう一度挑戦してもよい）。
- **出発できるのは1日2回**（2026-10-17 に1回から変更）。それぞれで、新しい階層に進むか、前の階層にもう一度挑戦するかを選ぶ。**知恵の試練は出発ごとに新しい4問**（2026-10-17 決定。1日に出発できる回数まで。2回目にはその日もう出した問題は出さない）。正解数と加護は、その出発の試練の結果で決まる。休みの日に解いた試練は、その日の1回目として数える。
  - **土曜と日曜は4回まで**（2026-10-25 保護者が決定）。知恵の試練も同じく、その日4回（最大16問）まで。回数は保護者画面で変えられる（平日の回数と土日の回数を別々に。土日ははじめ4回）。**その日に出した問題は、まちがえた問題もふくめて、その日のうちはもう出さない**。問題が足りないときだけ、その日に出した回数が少ないものから出す。
  - **まちがえた問題は、次の2日間は出さない**（2026-10-25 保護者が決定。例：月曜にまちがえた問題は、火曜・水曜は出ず、木曜からまた先に出る）。その教科で出せる問題がなくなったときだけ、この決まりをはずす。
- もう一度挑戦した階層の報酬は、**新しい階層と同じしくみ**（浅い階層なので、もともと敵も報酬も弱め）。
- **冒険の時間は保護者が設定する**（はじめは5分）。
- **7階層ごとにボス戦**。曜日ではなく階層で数える（休んだ日があれば、その分ボスが先になる）。ダンジョンの階層は7の倍数（3.5を参照）。
- 流れ3のドリルは**「毎日4問」そのもの**。結果はドリルの記録に入る。
  - 教科は今のまま、算数・国語・理科・社会を1問ずつ。
  - 出題の順：正解した回数が少ない問題が先（正解すると大きく後回しになる）。同じ回数なら、直近のテストの問題（2026-10-20 追加。教科ごと） → テストでまちがえた問題 → 正答率の高い問題の順。**3日後の復習はやめる**。まちがえた問題は優先度が下がらないので、すぐまた出る（正解するまで出つづける）。
  - **ドリルの新しい名前は「知恵の試練」**（決定）。
- **知恵の試練はゲームの中だけで解く**（決定）。ゲームができあがったら、ドリルだけの画面は使わなくなる（それまではドリルだけの画面を使う）。
- **ゲームの中の知恵の試練は、ゲーム風の飾り**（決定）。解き方は今のドリルと同じ（図への書きこみ、メモもある）で、まわりの飾りだけ神殿などにする。
- **4問を解き終えないとダンジョンに入れない**（正解しなくてもよい。解き終えれば扉が開く）。
  - **問題が読みこめないとき**（2026-10-22 保護者の希望・作った）：「もう一度」と「問題をとばしてダンジョンへ（加護なし）」が出る。とばすと、知恵の試練は0問正解のあつかい（加護・宝玉なし）で、ドリルの記録には何も入らない。遊んだ記録には「試練なし」と出る。
  - 問題と記録の読みこみは60秒まで待つ（ほかは30秒）。読みこみにかかった秒数と失敗した理由（時間切れ・つながらない・GAS のエラー）は端末に最近20回分を残し、保護者画面の「問題の読みこみの記録」で見られる（原因を調べるため）。
- **4問の結果で変わるもの**
  - 素材の量：正解1問ごとに鉱石・魔石が＋15%（2026-10-18 に、宝箱のレア度から付けかえた）。宝箱のレア度にも少しだけ効く。
  - その日の加護：正解した教科ごとに、その日の冒険でだけ効くバフがつく。**教科ごとに決まった加護**（決定）。算数→物攻、国語→魔攻、理科→物防・魔防、社会→HP・MP、それぞれ＋10%（決定）。
  - クリア報酬：クリアしたときの経験値やお金が増える。
  - 試練の画面（6-1 で作った）：神殿の飾り。上に4教科のタブ（解いた教科は ○正解／×ざんねん）、左の上に問い（問題文・図）、左の下に教科ごとのメモ（えんぴつ・赤・消しゴム・ぜんぶ消す）、右に答えの欄と答え合わせ（2026-10-17 保護者の案。問題が長くても、右の答えの欄はスクロールしても見えたまま）。その日に解いた問いは、開き直しても解いたまま。**数字の答え（数字・分数）は、画面の数字のボタン（0〜9・小数点・1文字消す・ぜんぶ消す）で入れる**（2026-10-19。iPad のキーボードは種類によって記号の並びが変わり、使いにくいため。文字の答えは iPad のキーボード）。数字のボタンは答えの欄の下にくっつけ、答えの欄は画面の中におさまる高さにする。欄を選ぶと、その欄がボタンにかくれない位置まで動く（2026-10-20。答えの欄が多いとスクロールしないとボタンが押せなかったため）。**低い画面（スマホの横向きなど。高さ560以下）では、数字のボタンを2段（1〜6・⌫／7〜0・小数点・ぜんぶ消す）にし、上の見出しと教科のタブも小さくする**（2026-10-23。答えの欄が1つのとき、背の高いボタンが欄にかぶって入れられなかったため。iPad は今までどおり）。**答え合わせのボタンは、答えを入れていなくても押せる**（2026-10-23 保護者の希望。画面の不具合などで入れられないときに、先へ進めなくなるため）。入れていない欄があると、1回目は「まだ答えを入れていない欄がある」と知らせてボタンが「このまま答え合わせする」になり、もう一度押すと答え合わせする（入れていない欄は×）。
  - **増え方は正解ごとに少しずつ**（決定）：0問でもふつうの報酬がもらえ、正解1問ごとに少しずつ上がる（たたき台：クリア報酬は1問ごとに+25%、宝箱のレア度も1問ごとに少し上がる）。数字は遊んでみてから調整する。

## 3. パーティと操作（決定）

- プレイヤーキャラは3人。切りかえながら進む（選んでいないキャラは待機）。
- **切りかえたあと数秒は、もう一度切りかえられない**（決定）。
- **待機中のキャラは画面にいない**。戦うのは選んだ1人だけで、切りかえるとその場で入れかわる。待機中は攻撃されない。
- 戦闘不能になったキャラは、ステージクリアまで使えない（アイテムで復活できる）。
- **今のキャラが戦闘不能になったら、ゲームが止まり、次に使うキャラを自分で選ぶ**（決定）。
- **メニューを開いているあいだは、敵も時間も止まる**（決定）。
- **経験値と熟練度は3人とも同じだけ入る**（決定）。だれがたおしても全員に入る（戦闘不能のキャラには入らない）。
- **回復**（決定）：毎日の出発のときにHP・MPは全快。冒険中のHPはアイテムやスキルで回復する。**MPは自然に回復しない**（2026-10-18 に変更。MP回復薬で回復する）。
- 戦闘中のボタン：十字キー、攻撃、スキル1、スキル2、スキル3、キャラ切りかえ、メニュー。
- **iPad と PC の両方で遊ぶ**（決定）。iPad は画面のボタン（左に十字キー、右に攻撃・スキル3つ・切りかえ・メニュー）、PC はキーボード。iPad は横向きを想定（検討中）。

- **3人は自分で作る**（キャラクリ）：ゲームを一番最初に始めるときに、3人の名前・最初の職業・顔グラフィックを選ぶ。プレイヤー（子ども・保護者）ごとに別々に作る。**作れるのは3人だけ**（控えはない）。**3人が同じ職業でもよい**（決定）。
- **ダンジョンの中の見た目（ドット絵）は職業で決まる**（決定）。職業ごとに1つ。転職すると見た目も変わる。
  - **仲間のドット絵の決まり**（2026-10-17 保護者と決定）：16×24点、FF6（SFC）の歩く絵の描き方に寄せる。保護者が描いた横向きの戦士と正面の素体がもと。正面は少し上から見下ろした形（頭が大きく縦長、目は顔の下より、あごは平ら）で、体は左右対称。同じ色を縦や横に長く続けない。5職業とも顔と体の形は同じで、変えるのは服と髪型だけ。男女どちらにも見える髪型・服にする。髪の色は顔の番号（8色）で変わる。
  - **基本職5つと一本道の上級職5つの絵を、保護者が描いた新しい絵にした**（2026-10-25。16×24点の正面・後ろ・横（左向き）。`js/game/sprites.js` の ART）。職ごとに色の一覧を持つ。歩く・走る・攻撃のコマは今までどおり絵を少しずつ書きかえて作る（横向きで歩くときの足は、職ごとの色で描き直した。ローブの職は、すその下から足を出す）。髪の色は顔の番号で変わる（絵の髪を明るい・ふつう・影・光に分けた）。**騎士・魔術師・黒魔道士は、かぶと・フードなので髪の色は変わらない**（保護者）。修行僧は頭の色も髪として変わる。組み合わせの上級職（魔法剣士・忍者・剣闘士・聖騎士・賢者）は前の絵のまま。
- **顔グラフィックは複数の中から選べる**（できれば。無料で公開してよい素材が見つかる範囲で）。メニュー・ステータス・会話の画面に出る。職業を変えても顔は変わらない。
  - **顔の絵**（2026-10-18 決定）：保護者が Gemini で作ったたたき台（男4人・女4人）を、48×48 点のドット絵にしたもの（`js/game/faces.js`）。顔の番号で、ダンジョンの中の髪の色も決まる（顔の髪に合わせる）。

  - **瘴気の森：10階（5階に中ボス、10階に主）**。毒沼が多い。短くてきびしい。
